# Commons — Social Media Platform

Commons is a full-stack social media platform built using HTML, CSS, JavaScript, Node.js, Express.js, and PostgreSQL/Supabase.

## Features

- User profiles
- Create and manage posts
- View posts
- Comments
- Like and unlike posts
- Follow and unfollow users
- Explore users and posts
- Messaging
- Notifications
- Responsive user interface
- REST API powered by Express.js
- PostgreSQL database through Supabase

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL
- Supabase

### Development Tools
- Git
- GitHub

- Postman
